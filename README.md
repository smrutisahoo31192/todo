# Minimal Todo App

## Overview
Simple browser-based todo app supporting add, complete, and delete actions.

## How to run
1. Open `index.html` in any browser

## Features
- Add todo
- Toggle complete (click on text)
- Delete todo (with confirmation dialog)

## Manual test steps
1. Open the app
2. Add a todo
3. Click the todo text → it should toggle completed
4. Click delete → confirmation dialog should appear
5. Confirm → todo should be removed
6. Cancel → todo should remain
