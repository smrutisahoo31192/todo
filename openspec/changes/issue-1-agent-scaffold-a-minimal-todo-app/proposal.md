## Title
Minimal Todo App Scaffold

## Summary
Create a minimal todo application to serve as a baseline for Agent Swarm testing.

## Goals
- Add, complete, and delete todos
- Run locally with minimal setup
- Provide basic usage/testing instructions

## Non-Goals
- Authentication, persistence beyond in-memory/localStorage
- Complex UI frameworks

## Acceptance Criteria
- Simple HTML/JS or Node app with add / complete / delete todo
- README with how to run locally
- Basic test or manual test steps documented

## Approach
Implement a small static web app using vanilla HTML/CSS/JS, storing todos in localStorage for persistence. Provide a lightweight Node static server script for convenience.

## Risks
- Browser storage limits (acceptable for minimal app)

## Rollout
- Single commit scaffold
