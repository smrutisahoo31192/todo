## Proposal

Scaffold a minimal React application using Vite that implements a simple Todo list.

### Goals
- Allow users to add todos
- Mark todos as complete/incomplete
- Delete todos
- Keep implementation minimal and easy to run locally

### Scope
- React + Vite app scaffold
- Single-page UI with basic state management (useState)
- No backend; in-memory state only
- README with setup instructions
- Basic manual test steps

### Out of Scope
- Persistence (localStorage or backend)
- Authentication
- Styling frameworks beyond minimal CSS

### Success Criteria
- App runs via `npm install && npm run dev`
- Todos can be added, toggled, and deleted
- README clearly documents usage and testing steps
